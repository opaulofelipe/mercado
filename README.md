# Lista de Mercado

Aplicativo em Python + Streamlit para organizar compras, acompanhar orçamento e marcar produtos no carrinho.

## Paleta
- `#9EE493`
- `#DAF7DC`
- `#ABC8C0`
- `#70566D`
- `#42273B`

## Como executar

```bash
pip install -r requirements.txt
streamlit run app.py
```

O banco SQLite `mercado.db` é criado automaticamente na primeira execução.
